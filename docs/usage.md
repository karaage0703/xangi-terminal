# 使い方

初回導入・サーバー起動・拡張登録は [セットアップ](../XANGI_SETUP.md) を参照してください。

## 普通のターミナルとして使う

- ターミナルへ直接入力し、Enterで実行。コマンド欄もEnterまたは「実行」で即座にシェルへ送ります。**確認チェックやAIの解説取得は不要**です。
- コマンド欄のShift+Enterは改行。日本語変換中のEnterでは送信しません。
- 本物のPTYと継続するbashを使うため、`cd`・`export`・履歴・Tab補完・Ctrl+C・対話入力・全画面アプリに対応します。
- スマホではTab/Esc/↑/↓/Enter/Ctrl+Cを画面から送れます。ターミナルは画面上部に残り、入力・解説領域だけをスクロールします。
- シェルは `bash --noprofile --norc -i`。ユーザーの起動スクリプトは自動読込せず、コマンド履歴はファイルへ保存しません。
- シェルの接続中は60秒の制限なし。出力量はフロー制御し、ブラウザのスクロール履歴は3000行、再接続時の復元は直近256K文字です。画面の完全な復元は保証しません。
- 通信切断後10分まではシェルを保持します。「再接続」や再読込で戻れます。無接続中は出力を一時停止するため、大量出力するプロセスは待機する場合があります。
- 同じ認証セッションは最後に開いた1タブが操作します。別タブで開くと古い接続を切断します。
- 認証は8時間。期限切れ、ログアウト、サーバー停止でシェルを終了します。`exit`後は「再接続」で新しいシェルを開始します。

## AIは任意の補助

自然言語欄で400ms入力が止まると、候補を別のコマンド欄へ反映します。候補生成にはツール・環境調査・コマンド実行をしないよう指示し、仮想実行の結果はこの段階では表示しません。直接入力したコマンドには自動でAIを呼ばず、「仮想実行・結果を確認」で必要なときだけ説明を取得します。AIが停止していてもターミナルは使えます。

「仮想実行・結果を確認」は自動変換とは独立した操作です。xangiバックエンドはコマンド名の固定リストに依存せず、意味と副作用を調べて事前確認します。読み取りだけの候補はツールで実行し、変更する候補は読み取り調査や利用可能なdry-runで影響を確認します。パイプやスクリプト、アプリ固有CLIも同じ流れで扱います。あらゆるコマンドの実行や結果の完全再現を保証する機能ではありません。

## 接続と権限

コマンドはサーバーを起動したOSユーザーの権限で動きます。本人用の任意シェルであり、共有・不特定多数向けの隔離環境ではありません。子シェルに渡す環境変数はPATH/HOME/LANG/TERM/PS1/HISTFILEのみです。起動ユーザーが読めるファイルやネットワークへはアクセスできます。

HTTP/WS両方でHost・Origin・セッション認証を検査します。CookieはHttpOnly/SameSite、HTTPSではSecure。ログイン回数・入力サイズ制限を設けています。CSPはスクリプトを同一オリジンに限定し、xtermの表示用スタイルと同一接続先のWebSocketを許可します。

`TRUSTED_TAILSCALE_LOGIN` に本人のログイン名を設定すると本人アカウントで自動接続できます。127.0.0.1限定で待受し、Tailscale Serveから転送してください。loopbackからの `Tailscale-User-Login` が設定値と完全一致する場合だけ認証します。別の共有プロキシから任意ヘッダーを通さないでください。未設定時はxangiの拡張入口またはローカルの起動リンクを使います。

## ワークスペースとGit

上部の「＋」で、現在の作業フォルダに独立したターミナルを追加できます。同じフォルダでも複数開け、タブごとにcd・export・履歴・入力途中の文章を保持します。タブを押して切り替え、「×」で確認後に閉じます。最後のタブを閉じると新しいターミナルを用意します。最大8個です。別のフォルダから始めたい場合は「＋ フォルダ」や登録済みフォルダの選択欄も使えます。

非表示のタブでもコマンドと出力の読み取りは続きます。再表示用に直近256K文字を保存します。タブは閉じるまで保持しますが、ログアウト・認証期限（ログインから8時間）・サーバー停止で終了します。ブラウザを閉じるだけでは即座に終了しません。長期常駐サービスの管理用ではありません。AI確認中は終了を待ってからタブを閉じてください。

Gitボタンは現在のシェルの作業フォルダを5秒おきに読み取り、ブランチと変更件数を表示します。開くとステージ済み・未ステージ・未追跡・競合、追跡先のahead/behind、変更ファイル一覧とdiffを確認できます。追跡先との差は最後のfetch時点で、自動fetchやcheckoutはしません。未追跡ファイルの内容は表示しません。Git管理外・追跡先なし・detached HEADを区別します。Git処理は各5秒/出力1MiB制限で、超過や権限エラーは取得エラーとして表示します。

## バックエンドとワークスペースの切り替え

上部の「設定 → エージェント」でxangiの登録エージェントを選びます。選択したエージェントのワークスペース・指示・バックエンド・モデル・Effortを使用します。モデル等の変更はxangi側のエージェント設定で行います。選択はサーバーに保存され、別端末にも共有され、切り替えると古い候補を破棄します。実行中の確認がある場合は切り替えできません。直接のコマンド実行と作業フォルダには影響しません。

XANGI_URLを設定すると、初回はxangiの既定エージェントを選びます。次回以降はサーバーに保存されたエージェントを復元します。xangi本体の設定は変更しません。エージェントが削除された場合は一覧を確認し、選び直してください。

xangiバックエンドでも自然言語の入力が400ms止まると、自動で候補生成だけを開始します。ツールによる環境確認は「仮想実行・結果を確認」を押したときに依頼します。日本語変換中は待機し、処理中の追加入力は最新のものだけを順番に処理します。古い入力への回答は表示しません。「コマンドに変換」で手動更新、「仮想実行・結果を確認」で直接入力したコマンドの確認もできます。現在のcwdを含むxangi登録ワークスペースを使い、サブフォルダを含む場合は最も深い登録を選びます。登録がなければ登録場所を選択してください。

変更操作を行わず読み取り中心に調べるよう指示し、承認・権限を迂回する設定は送りません。ただし、これはツールを技術的に読み取り専用へ制限するsandboxではなく、実際の権限はxangiのバックエンド設定に従います。ツールでファイルを参照するため、選択したプロバイダーへ送る情報の範囲もその動作に依存します。

出力・終了コードはバックエンドの報告です。xangiのツール呼び出し履歴も取得しますが、履歴は呼び出しの記録であり出力を独立に検証するものではありません。隔離環境を自動構築する機能はありません。長い処理は最大10分待機します。受理済みの依頼は通信失敗時も同じ入力で取得を続け、新しい依頼を重複送信しません。受付結果自体が不明な場合は再送せず、xangi側の状態確認を案内します。ブラウザを閉じても上流の処理は継続する場合があります。

xangi連携を使わず、単独でOpenAI互換APIを利用する場合、サーバーの `.env` に `LLM_BACKENDS_JSON` を設定すると、複数のバックエンドを登録できます。未設定時は従来の `LLM_BASE_URL`・`LLM_MODEL`・`LLM_API_KEY` を使います。ID・名前・URL・モデルを指定し、キーは必要な接続先にだけ追加します。URL・キーは画面に渡しません。

```dotenv
LLM_BACKENDS_JSON='[{"id":"local","name":"ローカルLLM","llmUrl":"http://127.0.0.1:8001/v1","model":"your-local-model","disableThinking":true},{"id":"other","name":"別のLLM","llmUrl":"http://127.0.0.1:8002/v1","model":"your-other-model"}]'
```

xangiの登録ワークスペースを利用する場合は、`.env` に `XANGI_URL=http://127.0.0.1:18888` のように同じサーバーのxangi Web UIのURLを指定します。上部のワークスペース選択欄に登録済みの場所が自動で並び、選ぶだけで切り替わります。事前の追加操作は不要です。xangiの登録内容は変更しません。連携時はログインするたびにxangiでデフォルト設定されたワークスペースを最初の作業フォルダにします。取得できない・フォルダが存在しない場合は接続エラーを表示します。連携未設定時は `CWD` を使います。接続後は直接フォルダを指定することもできます。上流でBearer認証が必要な場合だけ `XANGI_TOKEN` を設定します。

## 環境を参照した結果プレビュー

選択中のxangiバックエンドへ、入力・cwd・OS・シェルを渡します。バックエンドは実際の対象を調べ、次の状態と、確認に使ったコマンド・cwd・出力・終了コードを返します。

- 実行済み（AI報告）: 候補全体を指定cwdで実行した報告と、ツール呼び出し履歴があります。空出力・非ゼロ終了コードも結果です。
- dry-run: 変更する候補自体は実行せず、副作用のない代替試行で確認した報告です。
- 予測: 読み取り調査を根拠に影響を予測しています。
- 確認不可: ツール・権限・対象情報などが不足しています。架空のパスや数値で補いません。
- 履歴未確認: 実行報告はありますが、ツール呼び出し履歴を取得できていません。

実行済みの報告には候補とcwdの一致を要求します。ただし、バックエンドが返した出力そのものを別プロセスで再実行して検証する処理はありません。PTYの環境変数・alias・関数とバックエンドのシェル環境は異なる場合があります。直接接続のOpenAI互換APIではツールを使わず、直下のメタデータを参考にした予測だけを表示します。

## 手入力なしで接続

- Tailscale本人認証を設定済みなら、URLを開くと自動接続します。「接続を終了」や手動接続の画面はありません。xangiへ戻る場合はヘッダーの「xangiホーム」を使います。
- ローカルではサーバー起動後に同じディレクトリで`npm run open`。60秒・一度限りのリンクをOSのブラウザで開きます（Linuxのxdg-open/macOSのopen。ヘッドレス環境では不可）。URLからチケットを除去し、通常のHttpOnlyセッションへ移行します。
- キー入力欄・「別の方法で接続」はありません。
- `xangi-extension.json`をlink/startすると拡張一覧に入口を追加できます。拡張を開くと、xangiから認証された拡張リクエストを受けて同じ端末のterminalから60秒・一度限りの接続リンクを取得し、自動接続します。xangiの拡張入口にアクセスできる利用者がterminalにも接続できるため、xangi側の公開範囲で利用者を制限してください。
- 認証の前提と制限は[認証と実行権限](design.md#認証と実行権限)を参照してください。

```sh
npm run check

```

### ブラウザ検証

`uv run --with playwright python -m playwright install chromium`でブラウザを用意し、別々のターミナルで以下のサーバーを起動します。これは固定のテストキーを使うloopback限定サーバーです。検証後に停止してください。

```sh
XANGI_FIXTURE=1 node test/fixture.mjs
# 別ターミナル
PORT=18923 node test/fixture.mjs
```

```sh
uv run --with playwright python test/browser_login.py
uv run --with playwright python test/browser_environment.py
uv run --with playwright python test/browser_workspaces.py
uv run --with playwright python test/browser_xangi.py
```

既存のChromiumを使う場合はCHROMIUM_EXECUTABLEで実行ファイルを指定します。画像はGit対象外のtest-resultsへ保存します。

通常サーバーを使う追加のスモーク検証は`test/browser_smoke.py`、入力競合やAI障害の検証は`test/browser_states.py`を使用します。`BASE_URL`・`CHROMIUM_EXECUTABLE`を指定でき、`TAILNET=1`で本人自動認証を使います。

### 設定とホームへの移動

上部の「設定」でエージェントを選択できます。「コマンド変換時に簡単な解説を表示」は初期状態でオンです。オフにすると候補の短い解説を隠します。表示設定はサーバーに保存して別端末と共有し、仮想実行の結果表示は変更しません。

xangiの拡張一覧から開くと、ヘッダー左上に「xangiホーム」が表示されます。元のxangiホームに戻れます。単独利用で戻り先がない場合は表示しません。

### ターミナルの見方

bashプロンプトは`作業フォルダ$`形式に色を付けて表示します。`ls`はディレクトリ等を色分けします（Linuxは`--color=auto`、macOSは`-G`。パイプ・ファイル出力時は色なし）。Gitブランチと変更数は上部のGitボタンで確認できます。`Tab 補完`でパスやコマンドを補完し、`↑ 履歴`で直前の入力を呼び出せます。「画面を消去」は表示だけを消し、「中断 Ctrl+C」は実行中の処理へ割り込みを送ります。個人の.bashrcやStarshipのインストールは不要です。

AIモデルの固定既定値はありません。xangi連携時は`LLM_*`を使いません。単独利用では`LLM_MODEL`に接続先が受け付けるモデルIDを明示します。`LLM_DISABLE_THINKING`は既定falseで、対応するAPIに限ってtrueを指定します。AI未設定でも直接コマンドを実行でき、AI操作時に設定案内を表示します。

### AIの起動場所とコマンドの実行先

xangi連携では選んだエージェントのワークスペースをAI起動先に使います。AIはそのAGENTS.md（Claude向けはCLAUDE.md）、エージェントの役割指示、terminal専用の依頼を受け取ります。

画面の作業フォルダと`cd`先は、直接実行と仮想実行の対象です。AI起動先とは独立しており、実行先を変更しても選択中のエージェントのワークスペースは変わりません。実行先を含むxangiワークスペースの登録もAI依頼の条件ではありません。選択中のエージェントが削除済みならAI操作を止めて案内し、実行対象のワークスペースを代用しません。

これは指示の分離であり、ファイル権限やsandboxの分離ではありません。CLIに共通するグローバル指示は残り、AIの確認環境とPTY内のexport・alias・関数は共有しません。

### 端末間での設定共有

エージェント選択と解説表示はサーバーの`.runtime/preferences.json`へ保存します。同じterminalサーバーへ接続する認証済み端末で共有し、再起動後も復元します。設定画面を開いた時・画面へ戻った時・表示中の約5秒ごとに取得します。AI処理中のエージェントは途中で変更せず、完了後に反映します。保存に失敗した場合は画面にエラーを出し、成功扱いにしません。

既存のブラウザ保存値は共有設定を上書きしません。初回は設定で共有したいエージェントを選択してください。作業フォルダ・シェル・コマンド入力は各接続で独立しています。同じサーバーの設定として、項目ごとに最後に保存された値を使います。

### スマホでの入力

「ターミナル」と「自然言語・コマンド」を切り替え、それぞれを画面全体の作業領域で使えます。ターミナルを直接タップして入力します。自然言語やコマンドの編集中はターミナルを隠し、実行後は出力側に戻ります。入力途中の自然言語は切り替えても保持します。自然言語・コマンド側は通常のページスクロールを使い、実行ボタンを入力欄に重ねて固定しません。キーボードで表示領域が狭いときはヘッダーと接続情報を省き、入力・実行の領域を確保します。PCでは従来どおり左右に並べます。

スマホではターミナルの見出しを省略し、消去・再接続・中断を1段に表示します。キーボードなどで表示領域が低くなると、ターミナル表示中は上部のヘッダー・接続情報・設定欄を隠します。キーボードを閉じると再表示します。

### macOSでの作業フォルダ追跡

LinuxとmacOSに対応し、どちらも拡張専用のbashを使います。AIにはサーバーのOS名を渡し、macOSではBSD系コマンドのオプションを使うよう指示します。
macOSは標準の`/usr/sbin/lsof`からシェルの実際の作業フォルダを取得します。`/tmp`が`/private/tmp`になるなど、シンボリックリンクは実体のパスで表示します。
取得できない場合はGit表示・AI確認をエラーにし、以前のフォルダを確認対象として使いません。macOSでは制御文字・バックスラッシュ・`^`を含むパスは、lsofのエスケープ表現と区別できないため確認対象にできません。通常の名前のフォルダへ移動してください。端末操作自体は継続できます。
