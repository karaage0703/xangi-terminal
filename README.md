# xangi-terminal

PC・スマホのブラウザから、サーバーのbashを使うターミナルです。自然言語でコマンドを提案し、解説・実環境での結果確認を確認できます。

## 主な機能

- Enterで直接実行。履歴・補完・Ctrl+C・対話入力・再接続に対応
- 自然言語入力とコマンド編集、常設ターミナルを同じ画面に表示
- 独立したターミナルタブ（同じフォルダにも追加可能・最大8個）、Gitのブランチ・変更ファイル・diff表示
- xangiの登録ワークスペースを利用、変換・解説用のバックエンド・モデルを切り替え（Codex・Claude等）
- Tailscale本人認証と、ローカルの手入力不要な接続

## 導入

LinuxまたはmacOS・Node.js 22以上・bashが必要です。[セットアップ](XANGI_SETUP.md)に沿ってサーバーを起動し、xangi拡張へ登録してください。単独利用の手順も同じ文書にまとめています。
